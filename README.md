# MAXPRO VDK

Премиальный сайт автомобильного бюро на Next.js.

## Разработка
`npm install`
`npm run dev`

## Сборка
`npm run build`

Первый экран собран по утверждённому визуальному референсу. Изображение hero временно использует существующий файл `hero.jpg.jpg` в корне репозитория; его можно заменить на финальный отдельный кадр автомобиля без текстовых элементов.
